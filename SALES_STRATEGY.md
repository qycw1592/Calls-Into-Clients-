# CIC Website Sales Strategy

The website should sell business outcomes, not AI novelty.

Core positioning: CIC is a business renovation company powered by AI. We identify revenue leaks across answering, lead capture, scheduling, follow-up, reviews, web experience, customer communication, and owner visibility; then install a coordinated system around the client's actual rules and workflow.

Conversion principles:
- Show the product before asking the prospect to trust it.
- Use interactive demonstrations instead of long feature lists.
- Adapt examples by industry so an owner can picture CIC in their business.
- Clearly separate illustrative/demo data from verified customer results.
- Sell faster response, more captured opportunity, better follow-up, easier operations, and clearer visibility.
- Present implementation as white-glove renovation rather than DIY software.
- Make human escalation and business-defined controls visible.
- Use the CIC blue/orange construction/renovation identity consistently.

Primary conversion path: understand problem -> watch CIC work -> explore what client receives -> configure recommended system -> book demo.
